IMPORTANT BEFORE PUBLISHING

4. Add real product photos and prices if you have them. Prices currently say "Ask price" because no prices were supplied.
5. Save and preview index.html on your phone or computer.

FREE PUBLISHING WITH GITHUB PAGES
1. Create/sign into a GitHub account at https://github.com/
2. Create a new public repository named delux-toys (or another available name).
3. Upload index.html to the repository's root.
4. Open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait a few minutes. GitHub Pages will show your live website URL in Settings → Pages.
7. Open the URL on your phone and test the product filters and WhatsApp enquiry form.

NOTES
